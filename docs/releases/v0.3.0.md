# PearlPod v0.3.0

Private prerelease for the CS43131 FakePod Nano, built locally with ESP-IDF v5.5.5.

- Adds personalized anime welcome and farewell screens. Boot renders its welcome frame without a splash timer; visible shutdown includes a brief farewell and returns to the library if cleanup cannot finish.
- Makes sync playlist-first, with the current song and album, overall changed-song progress, a measured whole-sync ETA, and clear preparation, waiting, failure and completion states.
- Saves completed playlists individually. After an interrupted sync, completed work can be discovered by the normal scanner and reused on retry; partial files stay hidden and retry from the beginning. This does not guarantee FAT durability under abrupt power loss.

Local host, sync and production LVGL checks cover progress/ETA, interruption/retry, hidden partial files, navigation and shutdown recovery. The power-screen firmware was app-flashed and hash-verified, then answered three serial status/power queries with playback ready, an empty error and live USB. Physical screen appearance, the held-button power cycle and a live sync with the updated NAS service remain device acceptance checks. This release rebuild has the same firmware source with updated version metadata; it does not imply another physical flash.

Update the host syncer from this tag as well as the device to get playlist/song progress messages. The repository's source archives contain the updated syncer and deployment tool. An older service remains compatible, with unavailable ETA. This publication does not deploy the NAS container or start sync on the Mac.

Download `pearl-player.bin` for an app-only update at `0x10000` that preserves settings. `bootloader.bin`, `partition-table.bin` and `flasher_args.json` support separate-region installation; `pearl-player-merged.bin` is a full image at offset zero and overwrites the NVS region. `known-working-c9e6efd.bin` is the previously device-verified recovery app, used by the bounded twenty-attempt recovery script. Verify all binary downloads with `SHA256SUMS`. `BUILD-MANIFEST.json` records the source revision, toolchain and asset digests.

From the repository, `tools/fetch-firmware.sh` downloads v0.3.0 by default and verifies its checksums; `tools/update.sh --check` checks local files without flashing. Firmware binaries are release assets only and remain outside Git history.
